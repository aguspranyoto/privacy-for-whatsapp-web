# Privacy for WhatsApp Web 🍉

A lightweight Chrome Extension designed to enhance your privacy while using WhatsApp Web in public spaces or around prying eyes. It automatically blurs sensitive information, which can be revealed simply by hovering over it.

## Features

- ⚡ **Master Toggle**: Quickly turn all privacy features on or off.
- 👤 **Blur User/Group Names**: Hides the names in your chat list sidebar.
- 💬 **Blur Last Message Preview**: Obscures the message previews in the chat list.
- 📝 **Blur Messages in Chat Room**: Blurs the actual messages and media within the active chat window, excluding sender names and timestamps so you can still follow the conversation context.

## Usage

1. Click on the extension icon in your browser toolbar to open the settings menu.
2. Toggle the features you want to use.
3. **Hover to reveal**: Simply move your mouse cursor over any blurred text or message to temporarily reveal it.

## Installation (Unpacked Extension)

Since this extension is loaded locally for development or personal use:

1. Open Google Chrome and navigate to `chrome://extensions/`.
2. Enable **Developer mode** by toggling the switch in the top right corner.
3. Extract `privacy-for-whatsapp-web.zip`
4. Click the **Load unpacked** button in the top left corner.
5. Select the `privacy-for-whatsapp-web` directory.
6. The extension should now be installed and active on WhatsApp Web!
